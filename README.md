# n8n-workflows
This workflow demonstrates a Retrieval-Augmented Generation (RAG) pipeline+ that processes documents and stores them in a vector database for AI-powered retrieval. The workflow starts with a manual trigger, downloads a file from Google Drive, loads and extracts its text content, and splits the text into smaller chunks using a recursive character text splitter. These chunks are then converted into vector embeddings using OpenAI Embeddings and stored in Pinecone Vector Store. This setup enables semantic search and allows AI applications to retrieve relevant document information efficiently when answering user queries.
